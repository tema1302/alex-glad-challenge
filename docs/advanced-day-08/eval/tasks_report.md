# Три типа задач: прирост тюна vs прирост промпта (day-08 s4)

Метрики по задачам: формат — full_match (day-07, 30 кейсов); факты — exact acc (72 вопроса по 36 выдуманным фактам); стиль — доля выполненных rule-ограничений (12 кейсов).

## Формат (day-07, Kaggle T4, один рантайм)

| Модель | full_match |
|---|---|
| base-none | 0.00 |
| base-prompt | 0.33 (Δпромпт +0.33) |
| tuned | 0.47 (Δтюн +0.47) |

## Факты (day-08 s1; tuned — Kaggle T4)

| Модель | exact |
|---|---|
| 1.5b base-none | 0.00 |
| 1.5b base-prompt | 0.58 (Δпромпт +0.58) |
| 7b base-none | 0.00 |
| 7b base-prompt | 0.69 (Δпромпт +0.69) |
| 1.5b-tuned, факты в контексте (RAG-режим) | 0.62 (base-no-context 0.00) |

## Стиль-тон (day-08 s4)

| Модель | score avg |
|---|---|
| style-1.5b | base-none 0.58; base-prompt 0.50 (Δ -0.08) |
| style-7b | base-none 0.69; base-prompt 0.81 (Δ +0.11) |
| style-tuned | base-none 0.62; base-prompt 0.67 (Δ +0.04); tuned 0.56 (Δ -0.07) |

## Выводы

1. **Формат** — оба рычага работают: промпт вытягивает parse_ok (0.00 → 0.33), тюн добавляет точность полей (0.00 → 0.47, Δтюн > Δпромпт по full_match).
2. **Факты** — живут в контексте, а не в весах: без контекста base набирает 0.00 у обеих моделей; подстановка фактов в промпт даёт +0.58…+0.69; тюненая модель в RAG-режиме сохраняет чтение фактов (0.62 — на уровне base-prompt 0.58 в другом рантайме).
3. **Стиль-тон** — промпт помогает не всегда (1.5B: −0.08; 7B: +0.11); тюн на todo-стиле не переносится на стиль (Δ −0.07, см. out-of-domain).

Правило дня: формат и повторяющиеся паттерны → тюн; факты и контекст → промпт/RAG; стиль → промпт (тюн не окупается).

# Day 8 — сценарий видео (5–8 минут)

## 1. Задача дня (0:00–0:45)

- Тезис: «Вчера натюнили модель под NL→todo. Сегодня — хирургия: где тюн
  реально работает, где бессилен и чем платит».
- Кадр: таблица трёх типов задач одним слайдом (формат / стиль / факты).

## 2. Факты: что тюн не добавит (0:45–2:00)

- Кадр: `gen_facts.py` — 36 выдуманных фактов («Алдон Глухарёв — главный
  инженер организации, основанной в 1879 году»). Тезис: таких сущностей
  нет ни в одном датасете — проверяем честно.
- Кадр: `eval_facts.py --modes none,prompt`:
  - none: «В каком году основана…?» → 0/72 exact у 1.5b и 7b. Модель
    уверенно выдумывает — но не попадает в gold.
  - prompt: те же вопросы, факты в system → 42/72 (1.5b), 50/72 (7b).
- Кадр: facts-tuned на T4: тюненая модель с фактами в контексте — 45/72;
  без контекста — 0/72.
- Вывод: факты подкладываются в контекст (RAG), а не в веса.

## 3. Цена тюна вне домена (2:00–3:30)

- Кадр: `eval_outdomain.py` — 24 кейва: чат, математика, перевод, код
  (gold по построению: python-code исполнён, math посчитан).
- Таблица: 1.5b base-none 0.36 → base-prompt 0.39 → tuned 0.42 (T4:
  base-prompt 0.50 → tuned 0.42). Просел в chat (0.33 → 0.17), остальное
  держится.
- Тезис: узкий тюн стоит ≈ −0.08 avg вне домена — для специализированного
  сервиса приемлемо, для универсального ассистента — нет.

## 4. Переобучение: свип чекпоинтов (3:30–5:00)

- Кадр: `loss.csv` — eval loss 0.0321 → 0.0219 → 0.0191 → 0.0191.
  Расхождения нет; минимум на шаге 90 (early stopping сработал).
- Кадр: `sweep_checkpoints.py` — таблица: valid 1/63 (base) → 55/63
  (эп.1) → 55 → 56 → 56 (эп.4).
- Тезис: качество насыщается после 1-й эпохи — 4 эпохи были трататой
  GPU-времени; точку останова выбираем по eval loss.
- Бонус-нюанс: при todo-priming тюненая модель лочится в JSON даже на
  чужих задачах (0.09 vs 0.22) — «переобучение формата» без роста loss.

## 5. Три типа задач: итоговая таблица (5:00–6:30)

- Кадр: `tasks_report.md`:
  - формат — tuned 0.47 > prompt 0.33 > base 0.00;
  - факты — только prompt/RAG (0.58–0.69, без контекста 0.00);
  - стиль — prompt нестабилен (1.5B −0.08, 7B +0.11), tuned 0.56 (−0.07).
- Кадр: style-кейсы с rule-скорером — «перепиши деловым стилем» проверяется
  ограничениями (без '!', без «круто», лимит слов), без LLM-судьи.

## 6. Правило дня и финал (6:30–7:30)

- Формат и повторяющиеся паттерны → тюн.
- Факты и контекст → RAG.
- Стиль → промпт, но измеряй прирост на своей модели.
- Переобучение контролируй по eval loss, а не по эпохам.
- Тезис-закрытие: «Тюн — не замена промпту и RAG, а инструмент с чёткой
  зоной ответственности; измеряй цену до выката».

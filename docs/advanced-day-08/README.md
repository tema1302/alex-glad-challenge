# ADVANCED Day 8 — границы файнтюнинга (2026-10-30)

День измерений на весах day-07: где тюн работает, где бессилен и чем платит.
Код и полные таблицы: [`training/day-08/`](../../training/day-08/README.md).

## Задание

> Границы файнтюнинга: факты (что тюн не добавит), потери вне домена,
> переобучение (кривые loss, точка расхождения, epoch-чекпоинты), три типа
> задач (формат / стиль-тон / факты): замеры прироста тюна vs прироста
> промпта. Формат: видео + код.

## Что сделано (все замеры — реальные прогоны)

- **s1 Факты** (#164): 36 выдуманных фактов (seed=42) + 72 вопроса
  (оригинал/парафраз). base без контекста — **0/72 у обеих моделей**;
  факты в system — 42/72 (1.5b) и 50/72 (7b); тюненая в RAG-режиме —
  45/72 (T4). Факты читаются из контекста, чем больше модель, тем лучше.
- **s1-доп: факты в весах** (#180, CPU): Qwen2.5-0.5B + LoRA, обучение
  на 36 фактах (30 эпох, train loss 0.0009). Recall **26/36** в обучающей
  и **25/36** в переформулированной формулировке против base-none 0/72 и
  base-prompt 36/72 (50%). В веса факты закладываются ненадёжно и только
  под упоминание сущности; промпт управляемее. Разбор «один факт — четыре
  режима»: `eval/facts-trained/report.md`.
- **s2 Потери вне домена** (#165): 24 кейса (chat/math/translate/code, gold
  по построению). Цена тюна ≈ **−0.08 avg** (tuned 0.42 vs base-prompt
  0.50, T4); chat просел 0.33 → 0.17, математика/перевод — нет.
- **s3 Переобучение** (#166): свип чекпоинтов 30/60/90/116 (эпохи 1–4).
  Valid full_match: 1/63 (base) → 55/63 (эп.1) → 56/63 (эп.3–4) —
  насыщение после 1-й эпохи, деградации нет; eval loss ↓ монотонно
  (0.0321 → 0.0191), расхождения нет. Нюанс: при todo-priming тюн жёстче
  лочит формат (0.09 vs 0.22 base), при нейтральном промпте — нет.
- **s4 Три типа задач** (#167): единый отчёт. Формат — тюн лучше промпта
  (0.47 / 0.33 / 0.00); факты — только промпт/RAG; стиль — промпт
  нестабилен (1.5B −0.08, 7B +0.11), тюн не переносится (−0.07).
  Стиль-проверка — 12 кейсов с rule-скорером ограничений (без LLM-судьи).

## Выводы

1. Формат/паттерны → тюн; факты/контекст → RAG (в веса — ненадёжно,
   см. s1-доп); стиль → промпт с проверкой.
2. 463 примера × 4 эпохи — переобучения нет, но 1–2 эпохи дают то же
   качество: выбирать точку останова по eval loss.
3. Цена тюна вне домена умеренная — для узкого сервиса приемлемо.

# Гайд: как записывать видео по дням челленджа

Как записать демонстрацию работы дня (дни 1–10 + advanced): инструменты,
структура ролика, чек-лист записи и публикации. Сценарии по дням — в
`docs/advanced-day-NN/video-script.md`.

## 1. Инструменты

| Что | Инструмент | Зачем |
|---|---|---|
| Запись экрана | **OBS Studio** (бесплатно, Windows/Mac/Linux) | сцены, горячие клавиши, запись в MKV/MP4 |
| Альтернатива | Xbox Game Bar (Win+G) — уже в Windows | если лень ставить OBS; без сцен |
| Монтаж (опционально) | CapCut / DaVinci Resolve (free) | таймлапсы, обрезка пауз, титры |
| Сжатие/конвертация | ffmpeg: `ffmpeg -i in.mkv -c:v libx264 -crf 23 -preset medium out.mp4` | OBS пишет MKV — конвертируем в MP4 для Диска |
| Микрофон | любой петличкой/гарнитурой | голос важнее камеры; камеры может не быть вообще |

### Быстрая настройка OBS (5 минут)

1. Настройки → Видео: базовое разрешение 1920×1080, FPS 30.
2. Настройки → Вывод → Запись: формат **MKV** (не теряется при сбое),
   качество «Регулируемое» CRF 15–20, битрейт 8–12 Мбит/с.
3. Источник: «Захват экрана» (или «Захват окна» для терминала/браузера).
4. Микрофон: добавить «Ввод аудио», уровень так, чтобы пики были в жёлтой
   зоне; галка «Мониторинг выключен».
5. Горячие клавиши: «Начать запись» / «Остановить запись» (например,
   Ctrl+Shift+R), «Пауза» (Ctrl+Shift+P).
6. Тестовая запись 30 секунд → посмотреть звук и читаемость текста.

## 2. Подготовка экрана к записи

- **Терминал** (PowerShell/Windows Terminal): тёмная тема, шрифт
  моноширинный 16–18pt, масштаб окна 110–125%, окно на полэкрана.
  Цветной вывод (`--color`) — по вкусу, главное — читаемость.
- **Редактор** (VS Code): масштаб Ctrl+= до 14–16pt, скрыть лишние панели,
  включить тему с высоким контрастом.
- **Браузер** (для report.html / HF / Kaggle): масштаб 80–100%, скрыть
  закладки (Ctrl+Shift+B), режим инкогнито — без лишних вкладок.
- Убрать с рабочего стола личное; выключить уведомления
  («Фокусировка внимания» в Windows).
- Прогон заранее «прогреть»: модели должны быть скачаны
  (`ollama list`), Kaggle-ноутбук создан — запись не должна ловить
  загрузки по 5 минут (кроме случаев, когда загрузка — часть демо).

## 3. Структура ролика дня (5–8 минут)

По шаблону `video-script.md` дня:

1. **Задача** (30–60 с): что делаем и зачем, одним кадром/слайдом.
2. **Данные** (60–90 с): откуда, как чистили, сколько осталось
   (реальный терминальный прогон подготовки данных).
3. **Прогон** (60–120 с): обучение/генерация/запуск — терминал;
   долгие операции сжимайте таймлапсом (2–4×) с подписью «ускорено».
4. **Сравнение** (60–120 с): base vs tuned / до vs после — таблица
   отчёта (report.html / report.md) рядом с живыми ответами модели.
5. **Выводы** (30–60 с): что изменилось, что не осталось, когда так
   делать не стоит.

Тайминг жёстко: **7 минут — потолок**. Лучше 5 плотных минут, чем 10 с
водой. Длинные артефакты (логи, full-таблицы) — в git-отчёте дня, в видео
— только ключевые строки.

## 4. Что показывать обязательно (по требованиям челленджа)

- Реальные терминальные прогоны (не «картинки терминала»).
- Цифры замеров: baseline vs результат дня (`run.json`, `baseline_report.md`,
  `tuned_report.md` и т.п. — по дню).
- Loss-кривая / артефакты обучения (для дней 6–10).
- Сравнение до/после на фиксированном eval-наборе, включая «где стало хуже».
- Финальный кадр: ссылка/путь на отчёт дня в репозитории
  (`docs/advanced-day-NN/README.md`).

## 5. Чек-лист ПЕРЕД записью

- [ ] Прочитан `video-script.md` дня; все команды прогнаны хотя бы раз
      всухую (ничего не падает).
- [ ] Модели/данные скачаны заранее; кэш тёплый.
- [ ] OBS: тест 30 с — звук чистый, текст читается с телефона.
- [ ] Терминал очищен (`cls`), история не содержит секретов
      (ключи, токены, `.env`) — **проверить `Get-History` и eye-check**.
- [ ] Окна разложены: терминал + браузер/редактор; вторые мониторы
      отключены от записи.
- [ ] Секундомер/план таймингов под рукой.

## 6. Чек-лист ПОСЛЕ записи

- [ ] Просмотреть ролик целиком: слышно голос, нет секретов на экране,
      нет личных данных.
- [ ] Конвертация в MP4 (H.264, CRF 23) если писал в MKV:
      `ffmpeg -i day-N.mkv -c:v libx264 -crf 23 -c:a aac out.mp4`.
- [ ] Размер до ~500 МБ для Диска (при необходимости CRF 26 / 720p).
- [ ] Имя файла: `day-NN-<slug>.mp4` (например, `day-07-nl2todo-dataset.mp4`).
- [ ] Загрузка на Яндекс.Диск → «Поделиться» → скопировать ссылку.
- [ ] Ссылку вставить в `docs/advanced-day-NN/README.md` (строка «Видео»)
      и отправить в чат челленджа (дедлайн — 14:00 следующего дня).

## 8. Типовые ошибки (не повторять)

- Запись «в один дубль» без плана → 20 минут материала, 2 минуты смысла.
- Секреты в кадре: открытый `.env`, `printenv`, история команд с ключами.
- Мелкий шрифт: на превью телефона текст нечитаем.
- Смотреть на терминал молча >15 секунд: комментируйте каждую команду.
- Загрузка моделей/датасетов в кадре без надобности (таймлапс или вырезка).
- Видео без git-отчёта дня: челлендж оценивает «видео + код» парой.

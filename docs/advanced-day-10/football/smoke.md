# Смоук выката/отката футбольной tuned-модели (day-10 football)

Прогон 2026-10-31. Сервис: `pnpm dev -p 3100` (127.0.0.1:3100).
Env выката: `LOCAL_LLM_BASE_URL=http://127.0.0.1:11434`,
`LOCAL_LLM_MODEL=qwen2.5:0.5b-instruct`,
`LOCAL_LLM_TUNED_MODEL=qwen2.5-0.5b-football`. Админ-сессия — cookie
через `POST /api/auth/login`.

## 1. Конфигурация переключателя

`GET /api/local-model` →

```json
{"ok":true,"base":"qwen2.5:0.5b-instruct","tuned":"qwen2.5-0.5b-football","active":"qwen2.5:0.5b-instruct","switchable":true}
```

## 2. Стартовое состояние — base

`POST /api/agent {prompt: "«Челси» дома обыграл «Арсенал» 2:1. Голы: Мудрик
(34′) и Галлагер (78′); у «Арсенала» отличился Троссар (56′). Матч прошёл
в АПЛ.", llm:"local"}` → base отвечает прозой-пересказом, с
галлюцинациями («Матч прошёл в Венеции», «АПЛ 2021-2022»).

## 3. Переключение на tuned (без рестарта)

`POST /api/local-model {"model":"qwen2.5-0.5b-football"}` →
`active=qwen2.5-0.5b-football`. Тот же запрос `/api/agent` →

> В матче Челси дома обыграл Арсенал 2:1, забив голами Мудрик и Галлагер.
> У «Арсенала» Троссар забил первый гол.

Факты верные (все трое авторов, счёт, домашний статус), стиль дисциплинный —
в отличие от base. Строгий JSON-контракт при этом НЕ выражен: tuned-модель
обучена с полным system prompt `prompts.py`, а `/api/agent` шлёт свой
системный («Ты — ассистент…»). С полным контрактом (проверено напрямую
через Ollama) модель выдаёт точный JSON схемы day-07. Требование runbook:
к выкату tuned всегда прилагать её контрактный system prompt.

## 4. Откат (мгновенный)

`POST /api/local-model {"model":"base"}` → `active` снова base; повторный
запрос — снова base-стиль с галлюцинациями. Финальный `GET` → base,
switchable:true.

## 5. Контроль allowlist

`POST /api/local-model {"model":"typo-model"}` → `400` с сообщением
«неизвестная модель: ожидается "base", "qwen2.5:0.5b-instruct" или
"qwen2.5-0.5b-football"» — опечатка в имени не применяется.

## Вывод

Переключатель работает end-to-end: состояние меняется без рестарта,
запросы реально обслуживаются выбранной моделью (различие ответов base/
tuned наблюдаемо на одном и том же промпте), откат мгновенный, allowlist
env не пускает ошибочные имена. Качество в домене у tuned выше даже без
контрактного промпта; строгий формат требует полного system prompt.

# Бенчмарк: тюненая (distilled) vs базовая coder-1.5B (day-10 s2)

Замеры: `training/day-10/bench_model.py`, Ollama локально, temperature=0,
prompt «Напиши функцию is_palindrome(s) -> bool на Python», warm n=5.
Дата: 2026-10-30T22:03Z (обе модели подряд, одно железо RX 7600).

| Метрика | distilled (Q4_K_M) | base (qwen2.5-coder:1.5b-base) |
|---|---|---|
| Файл GGUF | 986 048 096 Б (sha256 b91286ee…) | н/д (пул Ollama) |
| Память (`ollama ps`) | ~1.2 ГБ | ~1.2 ГБ |
| Холодный старт (загрузка+генерация) | 4312 мс | 5687 мс |
| Ответ warm avg / p95 | 2191 / 2203 мс | 3841 / 3860 мс |
| Токены/с (warm avg) | 147.0 | 144.5 |

Чтение результатов:

- **Память одинаковая** — обе Q4-подобного размера; выигрыш distilled не в
  VRAM, а в поведении (SFT-стиль «только код» без лишней прозы).
- Warm wall у base выше в ~1.8 раза, но это в основном **разница длины
  ответа**: distilled выдаёт компактный код (~20 токенов), base — код с
  пояснениями (~150 токенов). Токены/с совпадают (147 vs 144.5) — скорость
  генерации железа идентична, разница — в характере выхода.
- Холодный старт distilled быстрее на ~1.3 с — меньше токенов на прогрев
  + модель чуть компактнее по стилю ответа.

Вывод: как инфраструктурная замена base → distilled «бесплатна» (та же
память, та же скорость генерации), а поведенчески даёт предсказуемый
короткий выход. Качество на домене — day-09 (18/30 vs 24/30 на eval, там
честно зафиксирован регресс: выкатывать под наблюдением).

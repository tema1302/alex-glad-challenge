# ADVANCED Day 9 — дистилляция (2026-10-30)

Проверка гипотезы «ученик 1.5B на ответах учителя 7B заменяет учителя на
узком домене». Код и таблицы: [`training/day-09/`](../../training/day-09/README.md).

## Задание

> Дистилляция: задача, где 1.5B уступает 7B; генерация ответов учителя с
> фильтрацией; обучение ученика (QLoRA); сравнение ученик до/после/учитель
> по качеству, скорости, стоимости. Формат: видео + код.

## Что сделано

- **s1 (#169)**: eval-набор 30 задач «спецификация → Python-функция»
  (rule-скорер исполняет тесты). Ученик до (coder:1.5b-base) **24/30**,
  учитель (coder:7b) **27/30** — разрыв есть.
- **s2 (#170)**: учитель сгенерировал решения 120 train-задач локально;
  rule-фильтр (все тесты зелёные) принял 120/120. Датасет дистилляции в
  messages-формате (в git).
- **s3 (#176)**: QLoRA-обучение ученика на Kaggle T4 (56.5 с): train loss
  0.0, eval loss 4.3e-05 — зазубривание пула. Eval ученика: 18/30.
- **s4 (#177)**: сравнение — ученик после (18/30) хуже ученика до (24/30)
  и учителя (27/30); экономика ученика реальна (4× меньше VRAM, ~1.3×
  быстрее). Вывод: **не заменяет**; причины и рычаги — в README.

## Выводы

1. Дистилляция лёгкого пула (accept 100%) переносит формат, но не
   сложность: на unseen-задачах регресс относительно base.
2. Eval loss ≈ 0 при memorization — плохой сигнал остановки; нужен
   следящий downstream-eval.
3. Узкий выигрыш ученика — память/скорость; качество на сложных задачах
   пока у учителя.

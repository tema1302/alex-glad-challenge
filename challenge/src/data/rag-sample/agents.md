# Блог-агенты

Pipeline для Telegram-канала «Иди на факты глянь»: RSS → выбор топ-новостей →
пост в авторском стиле → фактчекинг. Готов к cron-автоматизации.

## Агент 1 — NewsFetcher

Парсит RSS (sports.ru, championat.com, BBC Sport), фильтрует свежие, через LLM
выбирает top-K хайповых (Челси, АПЛ, ЧМ, топ-игроки).

## Агент 2 — PostWriter

Пишет пост в стиле канала, используя 5 случайных образцов из `style_samples`
как few-shot. Резкий тон, CAPS для акцентов, шапка «Иди на факты глянь:»,
подпись `@lookatfacts`.

## Агент 3 — FactChecker

Сверяет факты поста с источником: имена, клубы, счета, цитаты. Возвращает
`verdict: ok | needs_revision` + список issues с severity.

## Хранение

Новости, посты и образцы стиля лежат в SQLite (`blog.sqlite`). Новость помечается
`used=1`, чтобы не брать повторно. Образцы стиля уникальны по тексту.

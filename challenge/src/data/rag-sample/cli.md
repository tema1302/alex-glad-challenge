# CLI: команды

Точка входа — `pnpm --filter challenge start -- <command>`.

## Демо дней

- `list` — список всех дней.
- `latest` — прогнать последний день.
- `day-NN` — прогнать конкретный день (например `day-21`). Дефис обязателен.

## Интерактивный чат

- без аргумента или `chat` — глобальный чат-REPL.
- `--strategy <name>` — `full | sliding | sticky | branching`.
- `--system <text>` — стартовый system-промпт.

## Блог-агенты

- `news` — pipeline: RSS → выбор топа → пост в стиле канала → фактчекинг.
- `news --hours 48 --top 3` — свои параметры.
- `news --publish` — опубликовать готовый пост в Telegram (только если verdict=ok).
- `seed-style` — залить образцы стиля канала в БД.
- `db-stats` — статистика БД.

## RAG (дни 21–22)

- `rag index [path]` — индексировать каталог документов.
- `rag query "<вопрос>"` — ответ по индексу; `--no-rag` — без индекса.
- `rag eval` — прогон 10 контрольных вопросов (RAG vs без RAG).

## Typecheck

Перед коммитом: `pnpm --filter challenge typecheck` — должно быть без ошибок.
Это единственный статический гейт: lint, unit-тесты и сборка не настроены.
